# Pi workflow hardening and larger-cap pilot

The 100k shared cap explains the repeated cancellations, but dependency setup, coordination friction and custom context rewriting were integration choices. OpenHands currently uses its standard single-agent driver, no equivalent shared-token cap and a two-hour timeout. Preserve one lead and two Pi teammates and report that these are different harness configurations.

1. Bootstrap explicitly pinned public runtime dependencies before model requests, with retained logs and a setup deadline. Keep dependency setup separate from benchmark tests.
2. Add start_team to create assignments, task-board items and real delegation messages together. Make finish_teammate an explicit completion/report/handoff action; incomplete reports remain incomplete.
3. Narrow per-role builtin tools while preserving configured external extension capabilities. Add configurable role token reservations, early warning and per-role cancellation without spending another role's reserve.
4. Keep Pi native history as default. Retain the custom write-history compactor only as an explicit opt-in, along with the placeholder guard.
5. Run configuration, setup, budget, team and SDK mock regressions; rebuild and run full Docker mock evaluator profiles.
6. Run one small real-model three-session fixture with actual file and evaluator assertions. Only if generation, teamwork and fixture tests pass, run one fresh jsonlines task with the same model, lead plus two teammates, a shared 1,000,000-token cap and enough time/turns, then evaluate the saved repository.

Outcome: the 54-test pre-pilot checks and full mocks passed; the small live team fixture passed 4/4. The conditional 1M jsonlines attempt ran and used 815,579 reported tokens, but strict per-role ceilings stopped implementation and lead integration before a reviewer handoff. Its saved source was diagnostically evaluated at 16/27 passed, with failed generation/team status retained. Role targets were then made advisory by default, and final 56-test/full-mock validation passed. No additional paid run was made; live validation of the advisory correction remains pending.
